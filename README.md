# DrainFix campaign page

Plain static site, no build step. Upload everything in this folder to the repo root
(replace the old files), then Settings > Pages > Deploy from branch > main / root.

- Phone: 074 064 2297
- Tracking: the page fires a `contact_click` event on every call/WhatsApp tap.
  Paste your Google tag (gtag.js) snippet into `<head>` of index.html to count them as conversions in Google Ads.
