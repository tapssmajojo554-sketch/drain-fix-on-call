# DrainFix Plumbing & Jetting campaign

This is a fast, static one-page campaign site for DrainFix Plumbing & Jetting. It uses the supplied imagery and accreditation logos, with no database or server-side runtime.

## Local preview

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/` and can be deployed to GitHub Pages or any static host. The repository root also contains the static assets needed for a direct GitHub Pages branch deployment: choose **Settings → Pages → Deploy from a branch → main / root**. If the repository is served from a subpath, set the Vite `base` option to that repository path before building.
